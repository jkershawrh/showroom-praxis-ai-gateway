= Govern AI Model Access with Praxis

Stop duplicating model credentials, endpoints, and provider-specific
integrations across application teams. In this solution-architect-led
experience, submit a live request through Praxis, prove the OpenShift credential
and exposure boundaries, and map the pattern to your architecture.

== What you will learn

* Separate application and platform responsibilities for model access
* Explain application, gateway, model-serving, and OpenShift responsibilities
* Prove platform-owned credentials and a stable application contract
* Correlate a visible result with the exact request identifier
* Evaluate operations and governance choices relevant to your environment

== Prerequisites

* A web browser
* No prior OpenShift experience required

== Time estimate

The guided customer path takes approximately 20–30 minutes. Optional operations
and governance depth extends the experience to 60–90 minutes.
