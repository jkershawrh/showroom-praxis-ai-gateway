= Govern AI Model Access with Praxis — RHDP guided customer lab

This repository contains one progressive Showroom experience for Red Hat
solution architects and customer teams. The default path is a 20–30 minute
guided demonstration of governed AI model access. Optional modules extend the
conversation into platform operations and industry-sensitive governance.

This Showroom repository is public so RHDP can render the content and deploy
its automation. The private engineering quickstart is not a participant
dependency; customer-facing exercises use the provisioned environment directly.

This personal staging location is temporary because the current contributor account cannot create repositories in the `rhpds` organization. Transfer it to `rhpds/showroom-praxis-ai-gateway` after an organization owner creates or accepts the destination.

The model is accessed through shared MaaS only because RHDP labs require practical shared inference. MaaS is not taught as the Praxis architecture or production destination.

The catalog provisions model access through the standard RHDP LiteMaaS virtual-key workload used by the AI Quickstarts. The custom automation consumes `litellm_api_endpoint` and `litellm_virtual_key` directly and writes the endpoint and virtual key into an OpenShift ConfigMap and Secret without inserting them into Showroom pages, user data, Argo CD parameters, or terminal history. The virtual-key workload also owns key cleanup when the lab is destroyed.

This repository follows the Publishing House monorepo pattern:

* `content/` contains the guided customer journey and optional technical depth.
* `automation/ansible/` creates sensitive runtime configuration.
* `automation/gitops/` deploys Praxis and the OAuth-protected learner UI.
* `qa-automation/` contains live health and end-to-end gates.
* `publishing-house/` records the intake specification and publication prerequisites.
* `docs/sa-presenter-guide.md` contains presenter preparation, talk tracks,
  discovery prompts, and recovery guidance.
