= Govern AI Model Access with Praxis — RHDP Lab

This repository contains one progressive Showroom lab with three tracks: governed access, platform operations, and industry-sensitive governance. Track 1 is also published independently as the short quickstart experience.

The repository remains private during development. RHPDS provisioning and learner environments therefore require authorized GitHub access until the content is approved for broader publication.

This personal staging location is temporary because the current contributor account cannot create repositories in the `rhpds` organization. Transfer it to `rhpds/showroom-praxis-ai-gateway` after an organization owner creates or accepts the destination.

The model is accessed through shared MaaS only because RHDP labs require practical shared inference. MaaS is not taught as the Praxis architecture or production destination.

The catalog provisions model access through an RHDP `MaaSSandbox`. The custom automation consumes `maas_sandbox.credentials[0]` directly and writes the endpoint and virtual key into an OpenShift ConfigMap and Secret without inserting them into Showroom pages, user data, Argo CD parameters, or terminal history.

This repository follows the Publishing House monorepo pattern:

* `content/` contains the three-track Showroom lab.
* `automation/ansible/` creates sensitive runtime configuration.
* `automation/gitops/` deploys Praxis and the OAuth-protected learner UI.
* `qa-automation/` contains live health and end-to-end gates.
* `publishing-house/` records the intake specification and publication prerequisites.
